# PDF TOOLS
---
This is a simple web app with useful Pdf tools built with html css and js.

it has a home screen where all tools can be accessed. Now it has only 1 tool. In later ships more tools will be added.

## PDF Merger
---
Merge multiple pdfs into a single one directly from browser.

Features
- Select multiple Pdfs at once
- add more pdfs later
- remove files if needed

## Tech used 
---
- HTML
- CSS
- JS
- GITHUB PAGES
- PDF-lib.js
